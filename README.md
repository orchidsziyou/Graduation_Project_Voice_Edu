# 智能随堂测验生成系统 - 用户使用手册

## 一、系统概述

### 1.1 产品简介

智能随堂测验生成系统是一款基于AI技术的教育辅助平台，通过语音识别和大语言模型，帮助教师快速将课堂录音转换为测验题目，实现随堂测验的智能化生成与管理。

### 1.2 核心功能
- **语音转写**：支持云端（科大讯飞）和本地（Vosk）两种转写模式
- **AI出题**：基于转写文本，自动生成选择题或主观题
- **班级管理**：创建班级、管理成员、推送题目
- **答题系统**：学生在线答题、自动判题、进度跟踪

# 1.3 系统部署

系统部署有以下两种方案：

### 方案一：使用构建好的包进行安装

下载好的包里面的内容如下所示：
![[Pasted image 20260421152629.png]]

由于vosk本地转写的模型很大，因此没有放在包里面，需要自行下载，下载的地址如下：
```
https://alphacephei.com/vosk/models/vosk-model-cn-0.22.zip
```

下载完之后，把解压得到的文件夹改名为 *vosk-model-cn* ,并且放在* ./models/ * 文件夹里面，最终的文件夹层级如下所示：
```
部署目录/
├── demo01-0.0.1-SNAPSHOT.jar          # 后端 JAR 包
├── application.properties              # 配置文件
├── ...
└── models/                             # 模型目录
    └── vosk-model-cn/                  # Vosk 中文模型文件夹
```

下载完成之后，运行jar包，之后访问**localhost:8080**即可进入页面。如果要配合nginx使用，就根据自行配置来进行访问。
```
java -jar .\demo01-0.0.1-SNAPSHOT.jar
```

### 方案二：自行构建

在下载完本项目的源代码之后，可以使用maven包自行进行构建，具体的构建方式如下所示：

**（1）构建前端**
```bash 
cd vue-frontend  #进入存放前端的目录下
npm install 
npm run build 
```
**(2) 复制前端文件**
把刚刚构造前端生成的文件夹 *./vue-frontend/dist/* 放到 *src/main/resources/static/* 当中
```
cp -r vue-frontend/dist/* src/main/resources/static/
```

**(3) 打包后端**
```bash 
./mvnw clean package -DskipTests
```

**(4) 复制properties配置文件**
把`src/main/resources/application.properties`这个文件复制到构建完成的jar包所在的目录当中。

#### 部署运行

**1. 下载模型**
```
https://alphacephei.com/vosk/models/vosk-model-cn-0.22.zip
```
解压后重命名为 `vosk-model-cn`，放置在 构建完成的jar包下面的`./models/` 目录，并且修改properties配置文件当中的模型地址。

至此，输出文件夹的文件结构如下所示：
```
输出目录/
├── demo01-0.0.1-SNAPSHOT.jar          # 后端 JAR 包
├── application.properties              # 配置文件
├── ...
└── models/                             # 模型目录
    └── vosk-model-cn/                  # Vosk 中文模型文件夹
```

**2. 启动应用**
```bash 
java -jar target/demo01-0.0.1-SNAPSHOT.jar
```
**3. 访问系统**
浏览器打开：`http://localhost:8080`
有需要的，可以根据自行需求配置nginx。



### 1.4 技术架构
- **前端**：Vue 3 + Vite
- **后端**：Spring Boot 3 + JWT认证 + H2数据库
- **AI服务**：通义千问大模型 + 科大讯飞语音API + Vosk离线引擎

### 1.5 数据持久化方案
系统采用 **Spring Data JPA** 作为核心框架，配合 H2数据库实现高效的数据存取（使用的数据库可以根据自行需求更改）。
#### 核心技术栈
- **ORM 框架**：Spring Data JPA 
- **数据库引擎**：H2 Database (嵌入式文件型数据库)
- **持久层接口**：JpaRepository 

#### 技术优势
| 特性          | 说明                                       |
| :---------- | :--------------------------------------- |
| **自动化 SQL** | 通过继承 `JpaRepository` 自动生成增删改查逻辑，无需手写 SQL |
| **方法名查询**   | 支持 `findByUsername` 等语义化方法名自动解析为查询语句     |
| **事务管理**    | 基于 `@Transactional` 注解保证数据操作的原子性与一致性     |
| **轻量部署**    | H2 数据库以文件形式存储 ，无需安装独立数据库服务               |

#### 数据访问流程
1. **Entity (实体类)**：使用 `@Entity` 和 `@Table` 映射 Java 对象到数据库表。
2. **Repository (仓库层)**：定义接口并继承 `JpaRepository`，由 Spring 容器自动实现。
3. **Service (业务层)**：注入 Repository 实例，处理复杂的业务逻辑与事务控制。

### 3.2 语音转写功能

#### 3.2.1 手动上传音频

#### 使用场景
- 将课堂录音转换为文本
- 支持多种音频格式
- 提供云端和本地两种转写模式

#### 操作步骤

**步骤1：上传音频文件**
1. 进入"上传转写"页面
2. 点击"选择音频"按钮或拖拽文件到上传区域
3. 支持格式：
   - WAV格式：可选择本地或云端转写
   - MP3/M4A/FLAC：仅支持云端转写
![[Pasted image 20260413164718.png]]

**步骤2：选择转写模式（仅WAV文件）**
- **本地转写（Vosk）**：
  - 响应速度快
  - 仅支持WAV格式
  - 识别精度相对较低

![[Pasted image 20260413164814.png]]

- **云端转写（科大讯飞）**：
  - 识别精度高
  - 支持多种音频格式
  - 适合对精度要求高的场景
  - ⚠️ 需要网络连接
  - ⚠️ 处理时间较长

![[Pasted image 20260413164754.png]]

**步骤3：等待转写完成**


#### 注意事项
- 本地转写前请确保音频为16kHz、单声道、16-bit WAV格式（只要是wav格式的，上传完成之后可以自动转换）
- 云端转写会根据音频时长计费，建议上传前确认时长
- 转写完成后结果会自动保存（登录状态下）


#### 3.2.2 自动上传音频

在dashboard界面，点击进入自动录音界面，该界面可以实现自动录音并且自动上传转写的功能，不过转写的记录需要在*转写记录*页面查看。

![[Pasted image 20260414153531.png]]

录音默认为wav格式，录音默认10分钟分段一次，可以选择音频自动上传到服务器，也可以选择手动上传。
音频的转写方式默认为本地转写，如果有需要，可以修改为云端转写。

### 3.3 AI出题功能

#### 使用场景
- 基于课堂录音自动生成测验题目
- 支持选择题和主观题两种题型
- 可自定义出题要求

#### 操作步骤

**步骤1：完成语音转写**
- 先上传音频并完成转写
- 确保转写结果显示在文本区域
- 也可以在转写记录那里，使用转写的历史记录来出题
![[Pasted image 20260413165105.png]]

**步骤2：选择题型**
- 点击题型选择器
- 可选：
  - **选择题**：包含题干、4个选项、答案
  - **主观题**：包含题干、参考答案

**步骤3：添加自定义要求（可选）**
在"自定义备注"输入框中输入特殊要求，例如：
- "难度适中"
- "侧重基础知识"
![[Pasted image 20260413165144.png]]

**步骤4：生成题目**
1. 点击"AI出题"按钮
2. 等待8-12秒（AI处理时间）
3. 生成的题目将显示在结果区域

**步骤5：提取题干（选择题专用）**
1. 点击"提取题干"按钮
2. 系统自动从AI生成的文本中提取题干和选项
3. 可单独复制题干或选项

**步骤6：保存题目**
- 出题记录自动保存到数据库
- 可在"出题记录"页面查看历史
![[Pasted image 20260413165220.png]]

#### 提示词示例
系统自动构建的提示词包含：
```
请根据以下内容，生成 1 道选择题（包括题干、选项和参考答案）。

内容：[课堂录音转写文本]

【自定义要求】难度适中，侧重基础知识

生成的格式严格按照如下所示：
第一行：描述出题大纲
第二行：题目题干
第三行：选项（A,12 B,21 C,31 D,41）或空行
第四行：答案及解析
```

#### 注意事项
- AI出题需要网络连接（调用通义千问API）
- 出题质量取决于转写文本的准确性
- 建议出题后人工审核题目内容

## 四、常见问题

### 4.1 语音转写问题

**Q: 本地转写失败怎么办？**
A: 请检查：
- 音频格式是否为WAV

**Q: 云端转写时间过长？**
A: 原因可能包括：
- 音频文件过大（建议不超过50MB）
- 网络延迟
- 讯飞服务器繁忙
可以稍等一段时候，去转写记录那里查询


**Q: 转写结果不准确？**
A: 建议：
- 使用清晰度高的音频
- 减少背景噪音
- 尝试云端转写（精度更高）

### 4.2 AI出题问题

**Q: AI出题失败？**
A: 请检查：
- 是否已完成语音转写
- 网络连接是否正常
- 转写文本是否为空
- 通义千问API是否配置正确

**Q: 生成的题目格式不对？**
A: 可能原因：
- AI未严格遵守格式要求
- 转写文本质量较差
建议：手动调整或重新出题

**Q: 题干提取失败？**
A: 确保AI生成的题目符合格式要求：
- 第二行必须是题干
- 第三行必须是选项（选择题）
- 选项之间用空格分隔

### 4.3 班级管理问题

**Q: 无法创建班级？**
A: 请检查：
- 是否已登录
- 班级名称和编号是否为空
- 是否有创建班级的权限

**Q: 学生看不到推送的题目？**
A: 可能原因：
- 学生未加入该班级
- 推送已过期
建议：刷新页面或重新登录

### 4.4 答题问题

**Q: 提交答案后没有反应？**
A: 请检查：
- 网络连接是否正常
- 答案是否为空
- 是否重复提交

**Q: 选择题判分错误？**
A: 系统自动判断答案正确性，如发现问题：
- 联系教师修改题目答案
- 等待人工批阅

注意，当前选择题自动判题还是有问题的，但是班级里面学生答题情况是没有问题的，可以根据真实答案自行判断班级答题情况。
